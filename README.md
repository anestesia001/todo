# Todo App

Простое веб-приложение для управления задачами на Python с использованием Flask и MariaDB.

## Возможности

- Создание задач
- Просмотр списка задач
- Отметка задач как выполненных
- Удаление задач
- Хранение данных в MariaDB

## Технологии

- Python 3.12
- Flask
- PyMySQL
- MariaDB 11.4

## Проверка

Перейти в браузере:

http://localhost:5000

Для проверки состояния приложения:

```bash
curl http://localhost:5000/health
```

Ожидаемый ответ:

```json
{"status":"ok"}
```
